# 📊 Code Review Analytics Dashboard

This directory contains the automatically generated Code Review Analytics Dashboard and associated metrics data.

## 📂 Files

- **`review-dashboard.html`** - Interactive analytics dashboard (view in browser)
- **`review-stats.json`** - Summary statistics in JSON format
- **Historical metrics** - Collected from all PR reviews

## 🔍 View the Dashboard

### Option 1: GitHub Pages (Recommended)

If GitHub Pages is enabled for this repository:
1. Navigate to repository Settings → Pages
2. Set source to `main` branch and `/analytics` folder
3. Access dashboard at: `https://<username>.github.io/<repo>/review-dashboard.html`

### Option 2: Download and View Locally

1. Download `review-dashboard.html` from this directory
2. Open it in your web browser
3. All visualizations and data are embedded in the file

### Option 3: GitHub Actions Artifacts

1. Go to the **Actions** tab
2. Select the **Review Analytics Dashboard** workflow
3. Download the `review-analytics-dashboard` artifact
4. Extract and open `review-dashboard.html`

## 📈 Dashboard Features

The analytics dashboard provides:

### 📊 Visualizations

1. **Total Issues Over Time** - Track issue trends across PRs
2. **Issues by Severity** - Breakdown of critical/error/warning/info issues
3. **Issues by Source** - See which tools find the most issues (AI, Pylint, Security, etc.)
4. **Critical Issues Trend** - Monitor critical issue patterns
5. **Average Issues per PR** - Weekly aggregated averages
6. **Review Quality Score** - Quality trend analysis (0-100 scale)
7. **Top Issue Categories** - Most common issue sources
8. **Weekly Review Activity** - PR review frequency

### 📋 Key Metrics

- **Total Reviews** - Number of PRs reviewed
- **Total Issues** - Cumulative issues found
- **Avg Issues/PR** - Average issues per pull request
- **Quality Score** - Overall code quality trend

### 🔍 Insights

- Critical issue frequency
- Most active review periods
- Best quality PRs
- Tool effectiveness comparison

## 🔄 Update Frequency

The dashboard is automatically updated:

- ✅ **After each PR review** - Metrics collected automatically
- ✅ **Weekly** - Full dashboard regeneration (Mondays at 00:00 UTC)
- ✅ **On demand** - Trigger manually via GitHub Actions

### Manual Update

To manually trigger dashboard generation:

1. Go to **Actions** tab
2. Select **Review Analytics Dashboard** workflow
3. Click **Run workflow**
4. Select branch and run

## 📊 Metrics Data

### Data Collection

Metrics are automatically collected from:
- AI Code Review results
- Static analysis (Pylint, Flake8)
- Complexity analysis (Radon)
- Security scans (Trivy)

### Data Storage

- **Short-term**: Workflow artifacts (90 days)
- **Long-term**: Committed to repository in `analytics/` (indefinite)
- **Retention**: Review metrics artifacts kept for 365 days

### Data Format

Metrics are stored in JSON format:

```json
{
  "timestamp": "2026-02-24T10:30:00Z",
  "pr_number": 123,
  "repository": "owner/repo",
  "total_issues": 15,
  "critical": 2,
  "errors": 5,
  "warnings": 6,
  "info": 2,
  "by_source": [
    {"source": "AI Review", "count": 8},
    {"source": "Static Analysis", "count": 4},
    {"source": "Complexity Analysis", "count": 2},
    {"source": "Security Scan", "count": 1}
  ]
}
```
